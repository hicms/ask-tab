# Chrome 应用商店隐私权填写清单

根据 2026-09-27 的 AskTab 源码整理。标题对应商店后台的字段；填写时只复制英文代码框里的内容。标注“待处理”的项目暂不提交，提交前还需确认上传的软件包与源码一致。

## 单一用途说明

```text
AskTab is an AI assistant for completing browser-based tasks through chat. Users can ask it to understand web content, draft text, and carry out related browser actions. Its side panel, conversation history, browser tools, optional Google integrations, and scheduled tasks support this same assistant workflow.
```

## 需请求权限的理由

### 需请求 storage 的理由（本地存储）

```text
Stores extension preferences, account session state, agent and tool configuration, and other local settings so the assistant can preserve the user's configuration between browser sessions. Conversation and workspace data are also kept locally using IndexedDB.
```

### 需请求 scripting 的理由（页面脚本）

```text
Injects page interaction and content extraction functions into browser tabs used by assistant tasks. This enables the assistant to read page text, inspect page elements, and carry out requested interactions with the page.
```

### 需请求 tabs 的理由（标签页）

```text
Finds and identifies tabs by their titles and URLs, and opens, activates, navigates, or closes tabs as part of assistant browser tasks. Tab information lets the assistant work with the page relevant to the user's request.
```

### 需请求 tabGroups 的理由（标签页分组）

```text
Groups and labels tabs used by assistant sessions and supports tab organization tasks. This helps users identify related tabs and manage the browser pages involved in a task.
```

### 需请求 notifications 的理由（桌面通知）

```text
Displays desktop notifications for assistant messages received through configured messaging channels so users can notice a response while the extension interface is not in focus.
```

### 需请求 sidePanel 的理由（侧边栏）

```text
Displays the AskTab chat interface in Chrome's side panel, allowing users to interact with the assistant while keeping their current web page visible.
```

### 需请求 alarms 的理由（定时任务）

```text
Schedules assistant tasks, periodic checks for configured messaging channels, agent wake-ups, and configured backups. Alarms also help maintain background processing during active assistant operations when the extension service worker may otherwise become idle.
```

### 需请求 debugger 的理由（浏览器调试接口）

```text
Uses the Chrome Debugger API for assistant browser automation, including inspecting page structure, capturing page screenshots, and sending input actions. It also evaluates JavaScript supplied through assistant tools in a selected tab or a hidden extension document for task execution and data processing.
```

### 需请求 offscreen 的理由（隐藏文档）

```text
Creates a hidden extension document for JavaScript tools that need DOM parsing and Blob creation APIs unavailable in the service worker. This supports assistant data processing without opening an extra visible browser tab.
```

### 需请求 identity 的理由（账号授权）

```text
Authenticates optional Google integrations through Chrome's OAuth APIs when users connect a Google account. Authorized tokens allow the configured assistant tools to access Gmail, Calendar, and Drive within the granted scopes.
```

### cookies 权限（无需申请）

清单不再声明此权限，项目也未调用 Cookies API。`web_fetch` 通过浏览器标签页读取已登录的网页，普通请求可使用 `fetch` 的 credentials；这两种方式都不需要 `chrome.cookies` 权限。提交前核对上传包中的清单。

### 需请求 declarativeNetRequest 的理由（网络请求规则）

```text
Applies packaged request-header rules that remove the Origin header from XMLHttpRequest requests to localhost and 127.0.0.1 for local-service compatibility. It also applies a dynamic rule that removes Cross-Origin-Resource-Policy from image responses initiated by the extension so remote images can be displayed in the assistant interface.
```

### 需请求主机权限的理由（网站访问）

```text
AskTab works with websites selected by users and with service endpoints used by configured assistant tools. Host access allows browser tasks to extract web content, interact with pages, and request data needed to answer a user's request. Since these tasks can target arbitrary websites, the current package requests access to all URLs.
```

以上说明描述当前实现的访问范围，不代表已经证明更小范围或可选权限的设计无法满足需求。

## 您正在使用远程代码吗？（待处理）

当前不能因为扩展脚本已经打包就选择“否”。AI 生成的 JavaScript 可以传入 execute_js 工具，通过 Runtime.evaluate 执行。

主要执行路径使用 Debugger API，Chrome 的 Manifest V3 政策为该 API 规定了有限例外，但仍须符合其用途及其他政策。当前 Chrome 代码在调试器连接失败时还会调用 executeCodeFirefox，使用 scripting.executeScript 和 eval(expr) 执行代码；这条备用路径不能仅凭 Debugger API 的例外获得豁免。应先处理该路径，并核对上传版本中的其他动态执行路径。

以下英文如实描述当前行为，暂作说明草稿，不表示已经符合商店要求：

```text
AskTab includes a JavaScript tool for assistant tasks. Code supplied by the user or generated by the configured AI service can be executed to process data or interact with a selected page. The main Chrome execution path uses the Debugger API and Runtime.evaluate in a selected tab or hidden document. The current implementation also has a scripting.executeScript/eval fallback when debugger attachment fails.
```

修正实现后，应同步更新以上说明，使其与实际上传的软件包一致。选择“是”并填写理由，本身不代表实现就符合要求。

## 数据使用：哪些选项需要勾选

源码检查确认当前功能涉及下列数据类别，应按实际发布功能披露，包括仅在本地处理的数据：

| 后台选项 | 代码中对应的用途 |
| --- | --- |
| 个人身份信息 | AskTab 登录使用邮箱；可选的 Google 集成处理账号和联系人信息。 |
| 身份验证信息 | 登录凭据发送到 AskTab 服务；扩展处理账号令牌及可选集成的授权令牌。 |
| 个人通讯 | 聊天消息以及可选的 Gmail、消息渠道集成涉及通讯内容。 |
| 网络记录 | 浏览器工具为助手任务读取标签页网址和标题，范围小于完整浏览历史。 |
| 网站内容 | 浏览器工具提取网页内容并可截图，相关工具结果可能进入助手上下文。 |

“用户活动”还需结合发布版本中的任务、操作日志及服务端遥测确认；即使没有统计追踪，浏览器操作记录也可能属于该类别。本次检查未确认专门收集健康、支付或位置数据的功能，但这不能证明后端或全部可选集成都不处理这些数据。其余选项需核对实际服务行为，包括 IP 日志后再确定。

底部三项声明由发布者作出承诺。只有扩展、服务端及第三方的实际数据使用符合声明时才能勾选。本次源码检查不能验证外部服务的数据保留、数据出售、广告或模型训练行为。
